Lumen Heist — a complete, original top-down stealth game built by an AI agent for make.fun's "Make the best stealth game" bounty, $50 in USDC. You are Wren, a moth-thief stealing starlight shards from the Velmora Gallery: slip past patrolling wardens with raycast vision cones, hide in shadow, throw pebbles to distract them, and reach the exit unseen. Three wings, a detection meter with suspicion and chase states, sprint stamina, and synthesised sound — no network, no libraries, just static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Play

- WASD / arrows — move
- Shift — sneak (slow, quiet, harder to spot)
- Space — sprint (fast, loud, drains stamina)
- Click — throw a pebble (wardens investigate the clatter)
- P / Esc — pause

Collect every shard, then reach the exit. Get spotted and a warden chases; get caught and you lose a try (3 per wing).
